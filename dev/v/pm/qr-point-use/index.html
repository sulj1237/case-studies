01

OVERVIEW

한 줄로 이해하기

앱 미설치 회원의 포인트 사용 경로를 기존 차감 로직 위에 추가한다. 알림톡 QR로 확인한다

↓
02

PROBLEM

적립은 되는데 쓸 수 없는 회원이 남았다

앱 미설치 회원은 포인트를 적립까지만 가능하다

근거 — 사용 Flow 검토. 인증이 앱 바코드에 고정, 미설치 회원의 확인 경로 부재. 키오스크 전화번호 가입 포인트는 애초에 쓸 수 없다

고객

적립은 되고 사용은 막힘

적립까지만 가능, 사용은 앱 인증 필요

약국 직원

결제를 멈춰야 함

앱이 없으면 설명하거나 포인트를 포기시킨다

↓
03

DECISION

무엇을 골랐나

무엇을 확인할 것인가를 바꾸자 개발 범위와 책임 범위가 함께 줄어든다

01

본인인증 대신 사용 확인

확인 대상을 '이 결제 건에 쓸 사람인가'로 좁힌다

02

상태는 유효 · 만료 둘

복수 QR은 서버 기준 판단. 상태를 늘리지 않아 예외가 준다

03

잠금은 결제 건 단위

중복 차감 차단, 차감 · 복구는 기존 앱 바코드 재사용

↓
04

HOW

어떻게 만들었나

기존 앱 바코드 경로는 그대로 두고 병렬 경로 하나를 추가한다

↓
05

RESULT

무엇이 정해졌나

앱이 없어도 계산대에서 포인트를 쓴다. 인증 체계 없이 확인 경로만 더했다

01

개념

포인트 사용 확인용 임시 이용권. 화면 · 문구까지 같은 표현

02

상태 모델

유효 · 만료 둘뿐, 복수 QR 공존 허용

03

중복 차감 방지

결제 건의 포인트 기록 단위로 잠그고, 차감 · 취소 · 복구는 앱 바코드와 같은 코드
