02 PROBLEM · 연동은 작동하는데 기준이 없다

파트너몰과 케어팜은 이미 연동돼 있었다. 하지만 개인정보를 다루는 모든 지점에서 동의·고지·처리 기준이 비어 있었다.

04 HOW

어떤 경로로 들어왔나 → 동의를 받았나 → 무엇을 보내나 → 지금 어디까지 왔나 → 기록에 남았나. 앞 규칙이 정해져야 뒤 규칙이 정해지도록 순서 고정.

경로 → 동의 → 전달 항목 → 진행 상태 → 동의 기록. 이 순서가 곧 시스템이 확인하는 순서다.

05

정책

이미 돌아가던 외부 연동에서 빠져 있던 개인정보 처리 기준을 채운다. 가입·주문 흐름은 그대로 유지한다.

개인정보 보호와 서비스 연속성 사이에서, 전달 조건과 기록 기준을 명확히 정의했다.

06

예외 상황

무자격 신청·동의 미충족·자격 없는 주문 등 예외도 처리 구조 안에서 관리한다.

자격 없이 신청한 경우+
상담 연결 후 심사 → 자격 부여 또는 반려
주문 시 동의 안 한 경우+
다음 실행 때 재요청 · 사용은 가능
이미 케어팜 회원이 약정 맺는 경우+
기존 계정에 VIP 자격만 추가
전달 실패 시+
상태 '전달실패' 기록 · 재시도 가능
