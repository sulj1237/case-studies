PROBLEM

개인정보 처리 기준의 부재

기능은 이미 연결돼 있었지만, 개인정보를 다루는 모든 지점에서 동의·고지·처리 기준이 비어 있었다.

누락된 4가지 기준

가입 경로

경로별 처리 기준 부재

협력도매 약정·일반 메뉴·기존 회원 경로별 회원 구분·전달 범위가 상이함

개인정보

전달 조건 불명확

무엇을·언제·동의 후 전달할지 기준 없음

동의

동의 기준 부재

화면 동의와 실제 전달 시점의 동의 상태가 연결되지 않음

이미 케어팜 회원이 약정 맺을 때 자격 추가 절차 없음

04

SOLUTION

기존 흐름 유지와 정책 Layer 추가

기존 가입·주문 흐름은 유지하고, 경로 → 동의 → 전달 항목 → 진행 상태 → 동의 기록의 5단계 규칙을 그 위에 더했다.

경로 → 동의 → 전달 항목 → 진행 상태 → 동의 기록. 앞 규칙이 정해져야 뒤 규칙이 정해지도록 순서를 고정했고, 이 순서가 곧 시스템이 확인하는 순서다.

05

정책

이미 돌아가던 외부 연동에서 빠져 있던 개인정보 처리 기준을 채운다. 가입·주문 흐름은 그대로 유지한다.

개인정보 보호와 서비스 연속성 사이에서, 전달 조건과 기록 기준을 명확히 정의했다.

06

예외 상황

무자격 신청·동의 미충족·자격 없는 주문 등 예외도 처리 구조 안에서 관리한다.

자격 없이 신청한 경우+
상담 연결 후 심사 → 자격 부여 또는 반려
주문 시 동의 안 한 경우+
다음 실행 때 재요청 · 사용은 가능
이미 케어팜 회원이 약정 맺는 경우+
기존 계정에 VIP 자격만 추가
전달 실패 시+
상태 '전달실패' 기록 · 재시도 가능
