01

INTRO

기존 연동 구조와 이슈 발견

케어팜은 H사의 약국 대상 B2B 청구·CRM·재고관리 서비스다. 케어팜 재고관리에서 상품을 선택하면 KD몰로 이동해 주문하는 기존 연동이 구축되어 있었다.

02

PROBLEM

개인정보 처리 기준의 부재

케어팜과 KD몰 사이의 가입·회원·주문 연동은 있었지만, 경로마다 누가 어떤 조건으로 회원이 되고 정보가 전달되는지 기준이 명확하지 않았다.

개인정보 처리 기준의 부재

가입 경로

경로별 회원 처리 기준이 불명확

협력도매 약정, 일반 메뉴, 기존 회원 경로에 따라 가입과 회원 연동을 어떻게 처리할지 기준이 필요했다.

개인정보

전달 항목과 조건이 불명확

회원·약국 관련 정보 중 무엇을 어떤 조건에서 상대 서비스로 전달할지 정해져 있지 않았다.

동의

동의와 실제 전달 시점이 분리

제3자 제공 동의 여부가 실제 개인정보 전달 시점에 어떻게 확인되는지 연결 기준이 필요했다.

회원 자격

기존 회원의 약정 후 자격이 불명확

이미 케어팜 회원인 약국이 KD몰 약정을 맺을 때 회원가입과 KD몰 VIP 자격을 어떻게 구분할지 정리되지 않았다.

ANALYSIS

연동 구조와 정책 판단 기준 분해

기존 가입·주문 연동은 유지하면서 회원 자격과 개인정보 전달 조건을 각각 정리하고, 신청 이후 확인과 상담까지 이어지는 흐름을 설계했다.

04

SOLUTION

기존 흐름 유지와 정책 Layer 추가

가입 경로를 확인하고, 필요한 동의를 받은 뒤, 필요한 정보만 전달하도록 기준을 정리했다. 이후 신청·약정·자격 상태와 동의 기록을 이어서 관리한다.

Route → Consent → Data → State → Log. 앞 단계의 조건을 확인한 뒤 다음 단계로 진행한다.
