약국 포인트 기능 도입

약국마다 운영 방식이 다른 환경에서 운영 주체와 시스템 책임 범위를 나눠 다섯 접점의 공통 포인트 기준을 정의한 프로젝트

OVERVIEW

약국에서 적립하고 쓰는 포인트를 다섯 접점이 같은 기준으로 다루도록 설계한다. 운영은 약국, 기준과 기록은 시스템이다

핵심 — 약국별 독립 운영 위에 다섯 접점 공통 거래 기준을 얹는다

PROBLEM

약국마다 운영 방식이 다른데 다섯 접점이 같은 잔액을 읽고 쓴다. 거래 기준이 한 곳으로 모이지 않던 상태다

근거 — 약국 운영 환경 · 약사법 · 다섯 접점 기준 정책 검토. 적립률과 사용 조건이 약국마다 달랐고 접점별 처리 기준이 따로 있었다. 그래서 중복 적립 · 취소 누락 · 잔액 불일치가 생길 수 있는 구조다

약국

운영 방식이 제각각

적립률 · 사용 조건 · 만료 정책이 약국마다 다르다

거래

기준 부재

같은 영수증 중복 적립, 결제 취소 시 포인트 미반환, 접점 간 잔액 차이다

회원

앱 없이는 사용 불가

인증 · 바코드가 앱에만 있어 앱 미설치 고객은 적립까지만 가능하다

DECISION · 무엇을 골랐나

운영 주체와 책임 범위를 먼저 갈랐고, 나머지 규칙은 그 선을 따라 정해진다

01

운영은 약국, 기준은 플랫폼

본사가 잔액을 직접 고치면 분쟁의 최종 책임이 본사로 넘어온다. 본사 화면은 조회 중심, 조정은 약국이 사유와 함께다

02

사용 인증은 앱 바코드 하나

전화번호는 타인 사용 위험, 비밀번호는 현장 노출 위험이다. 로그인 상태 자체가 확인 수단인 앱 바코드로 고정한다

03

적립 기준은 실제로 낸 금액

결제금액 전체 기준이면 사용한 포인트에 다시 포인트가 붙어 약국 부담이 늘어난다. 거래번호로 중복을 막는다

포기한 것 — 앱 미설치 회원의 사용 경로다. 이 빈칸이 다음 과제(QR 포인트 사용)가 된다

HOW · 어떻게 만들었나

다섯 접점이 그 자리에서만 할 수 있는 일을 맡고, 기록은 한 곳으로 모인다

규칙내용
운영 단위약국별 독립 — 적립한 약국 안에서 쌓고 사용
적립 기준결제금액 − 사용 포인트 = 실제로 낸 금액
유효기간적립일로부터 5년 · 만료 14일 전 안내
회원 조건그 약국 약관 동의 + 고객앱 바코드 인증
취소전체 취소만 · 사용 포인트 복구 + 적립 포인트 회수

RESULT · 무엇이 정해졌나

다섯 접점이 같은 잔액을 두고 어긋나지 않는다. 운영은 약국, 기준과 기록은 시스템으로 갈랐다

01

공통 포인트 정책

운영 단위 · 적립 기준 · 유효기간 · 회원 조건 · 취소 처리

02

접점 간 동일 기준

고객앱 · 키오스크 · POS · 관리자 화면이 같은 기록을 쓴다

03

책임 경계

운영과 조정은 약국, 기준과 기록은 플랫폼이 맡는다

04

재사용 기반

차감 · 복구 로직을 QR 포인트 사용이 그대로 가져다 쓴다

다음 고도화 — 부분 취소와 약국 관리자 운영 화면을 더한다. 앱 미설치로 사용에 실패한 건수를 모아 QR 경로의 필요 규모를 정한다

NEXT · 한계와 다음 문제
